# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

This project targets **Expo SDK 57** so it runs on the Expo Go build currently published on the App Store / Play Store (v57.x; the iOS App Store only offers the latest Expo Go). Do not bump to a newer SDK without confirming Expo Go on the store supports it — otherwise the QR code fails with "Project is incompatible with this version of Expo Go".
